# LiquidGlass

LiquidGlass 是適用於 LSPosed 的 Android 液態底欄模組，透過系統級 Hook、取景與渲染技術，為支援的應用提供液態玻璃風格的底欄與介面效果。

本模組以 Android 15 以上、API 102 與 arm64-v8a 環境為主要適配目標，支援自訂底欄外觀、應用導覽適配、原生底欄隱藏、畫面取景與液態渲染等功能。
